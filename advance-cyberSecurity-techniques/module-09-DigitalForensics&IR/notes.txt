A systematic process to manage cybersecurity incidents
Ensures quick detection, effective containment, and complete recovery
Minimizes damage and restores normal operations efficiently
Developed based on NIST ands SANS guidelines

TRIAGE IN
INCIDENT RESPONSE

Incident ko quickly check, classify aur prioritize karna, taaki security team decide kar sake ki
 kaunsa incident kitna serious hai aur pehle kis par action lena hai.


 PRIORITIZING
BASED ON
SEVERITY & IMPACT


| Incident                            | Severity | Impact      | Priority |
| ----------------------------------- | -------- | ----------- | -------- |
| Failed login attempts               | Low      | Low         | Low      |
| Malware on one workstation          | Medium   | Limited     | Medium   |
| Employee account compromised        | High     | Significant | High     |
| Ransomware on critical server       | Critical | Very High   | Critical |
| Sensitive customer database exposed | Critical | Very High   | Critical |



CLASSIFICATION &
CATEGORIZATION
OF INCIDENTS

| Category                | Simple Meaning                              | Example                            |
| ----------------------- | ------------------------------------------- | ---------------------------------- |
| **Malware**             | Malicious software                          | Ransomware, Trojan                 |
| **Phishing**            | Fake message/email se trick karna           | Fake bank login email              |
| **Unauthorized Access** | Permission ke bina access                   | Stolen password se login           |
| **Data Breach**         | Sensitive data unauthorized access/exposure | Customer database exposed          |
| **DoS/DDoS**            | Service ko unavailable karna                | Website par huge traffic           |
| **Insider Threat**      | Authorized person se harmful activity       | Employee copying sensitive data    |
| **Web Attack**          | Web application ko target karna             | SQL Injection, XSS                 |
| **Policy Violation**    | Security policy ka violation                | Unauthorized software installation |
