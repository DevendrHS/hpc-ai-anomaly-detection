VULNERABILITY ASSESSMENT &
PENETRATION TESTING (VAPT)


￭ VAPT is a combined approach of two techniques:
• Vulnerability Assessment (VA) – Finding weaknesses.
• Penetration Testing (PT) – Exploiting weaknesses like a hacker
would.
￭ Both are used to check the security of systems, networks, and
applications, but each has a different purpose and depth.


VAPT EXAMPLE SCENARIO--

Let’s say a company launches a new online payment app.

The Vulnerability Assessment finds:
• Outdated software on the web server
• Missing HTTP security headers
• SQL Injection possibility in the login page


The Penetration Tester tries:
• Exploiting the SQL Injection to bypass login
• Gaining admin access to the backend
• Downloading the customer database

The report shows:
• Real damage possible
• How the attack was done
• Fixes needed to patch the app

PAYLOAD-----
A payload is the actual action that happens
 after an attacker successfully exploits a vulnerability.

it could :
￭ Steal data
￭ Create a reverse shell
￭ Open a backdoor
￭ Run a command

WHEN ARE PAYLOADS USED

• During the Gaining Access phase of penetration testing.
• After identifying a vulnerability that can be exploited.
• Sent via exploit code or manually delivered once access is gained.

PAYLOAD CRAFTING
Payload crafting means preparing or modifying a payload so that it works properly
 for a particular target or situation.

Exploit → The method you use to open the door.
Payload → What you carry/do after entering.
Payload crafting → Preparing that payload specifically for that building.

Payload-crafting tools 
 tools that help security professionals create or modify payloads for penetration testing.

EXPLOITATION
TECHNIQUES----

buffer overflow-
A buffer overflow happens when a program receives more data than the memory area can hold, 
causing the extra data to overwrite nearby memory.

SQL Injection (SQLi)
SQL Injection happens when an application incorrectly mixes user input with a database query, 
allowing the input to change what the database query does.

Cross-Site Scripting (XSS)---
XSS happens when a website accepts malicious script as user input and then
 displays/runs that script in another user's browser.


Command Injection
Command Injection happens when an application allows a user to insert operating system commands 
through an input field.

File Upload Exploit
A File Upload Exploit happens when a website allows users to upload files
 but does not properly check or restrict those files.

LATERAL MOVEMENT ---

Lateral Movement means that after an attacker gets access to one computer, they try to move to
